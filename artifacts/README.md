# Готовая поставка

`maxiimka-hackathon-2026-linux-amd64.tar.gz` — архив Docker-образа с рабочей
конфигурацией, токеном MAX и ключами провайдера. Загрузка:

```sh
docker load --input artifacts/maxiimka-hackathon-2026-linux-amd64.tar.gz
```

Образ получает тег `maxiimka:hackathon-2026`. Команды запуска — в основном README.
Архив размещается во вложениях GitHub Release; он исключён из обычного Git.

`maxiimka-hackathon-2026-source.zip` — исходники с текущими ключами и настройками
для локальной передачи. В нём нет окружений, `node_modules`, весов моделей и
самого Docker-образа. Для запуска готового контейнера достаточно архива образа.

`SHA256SUMS` содержит контрольную сумму Docker-образа.
`image.json` содержит платформу, идентификатор и размер готового образа.
