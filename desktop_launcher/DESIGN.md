# Лаунчер МаксИИмки

Небольшое настоящее окно Windows, 860 × 700; полноэкранного режима нет.
Интерфейс продолжает уже адаптированный gold static-card из Stageshow:
одна синяя основная кнопка, спокойные поверхности, реальные поля и короткие подписи.
Kit и отдельный STAGESHOW.md используются из webapp без второй копии компонентов.

Две части одного запуска: подготовка среды, затем мастер. Первое окно использует
стандартный tkinter, потому что .venv и сторонних библиотек ещё может не быть.
Для него вручную перенесены цвета, шрифт, отступы и иерархия из токенов МаксИИмки.
После установки pywebview и сборки открывается React-интерфейс в нативном окне.

Первый запуск: приветствие → MAX → провайдер → модель → распознавание →
дополнительные настройки. Вверху всегда шкала и названия шагов, внизу —
«Назад» и одно продолжение. Проверки сети не блокируют окно; неподтверждённая
поддержка остаётся неизвестной. В формы не подставляются вымышленные модели.

Повторный запуск: модель и состояние, независимый выбор панели и один режим
работы бота — терминал или фон. Нижняя кнопка запускает ровно один процесс.
Можно снова открыть настройки, панель и остановить запущенный процесс.

Используются Button, Card, Field, Row, Badge, Toggle и Meter из Stageshow.
Окно рисует Windows/pywebview; изображение рамки браузера внутрь не добавляется.
Локальный мастер недоступен обычному браузеру без нативного Python-моста.
