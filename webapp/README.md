# Интерфейс мини-приложения

React 18 + TypeScript + Vite, дизайн и компоненты из Stageshow.
Рабочая панель и API находятся в одном проекте; сборка обслуживается FastAPI.

## Обычный локальный запуск

Из корня проекта:

```powershell
.\start-miniapp-local.cmd
```

Скрипт собирает интерфейс, запускает бота и выдаёт локальную ссылку администратора.
Подробности: [инструкция для хакатона](../docs/miniapp.md).

Только сборка, без запуска бота:

```powershell
.\build-miniapp.cmd
```

Нужен Node.js 20.19+. Готовые файлы лежат в `webapp/dist`; каталог не хранится в Git.

## Разработка интерфейса

Из папки `webapp`:

```powershell
npm.cmd ci
npm.cmd run dev
```

Открывай [демонстрацию](http://127.0.0.1:5173/app/?demo=1).
Она показывает пример данных и не обращается к API. Дополнительные состояния:
`?demo=1&role=student` — без админки, `?demo=1&screen=settings` — настройки.
`?design=1` — статичная иллюстрация, адаптированная из gold `static-card`.

API в dev-режиме проксируется на `127.0.0.1:8000`. Для проверки настоящей
локальной авторизации используй сервер Python со сборкой по ссылке из терминала.

## Проверки

При работающем Vite на порту 5173:

```powershell
node scripts/verify-ui.mjs
```

Проверяются поиск, фильтры, клавиатура, просмотр, подтверждение удаления,
сохранение настроек, предупреждение о несохранённых изменениях, отсутствие
админки у ученика, экраны 1440/390/358 px и уменьшенное движение.
Установленный Google Chrome используется через `playwright-core`.
Адрес можно переопределить переменной `MINIAPP_TEST_URL`.

После сборки, без запущенного Vite:

```powershell
node scripts/verify-live-ui.mjs
```

Скрипт сам поднимает Python-сервер на свободном локальном порту, проверяет вход,
SQLite/Chroma, просмотр текста, настоящее сохранение и удаление, затем
останавливает свой сервер. База и настройки временные; ответы модели и
эмбеддинги заменены для работы без внешних сервисов. Рабочие данные не меняются.
Нужны установленное `.venv` в корне и предварительно собранный интерфейс.

Снимки и результаты записываются в `shots/`, который исключён из Git.
Python API также проверяется общим набором `python -m unittest discover -s tests -v`.

## Stageshow

[STAGESHOW.md](STAGESHOW.md) — отдельная копия скилла;
[DESIGN.md](DESIGN.md) — план и адаптация;
[REHEARSAL.md](REHEARSAL.md) — проверенные состояния и ограничения.
Копия kit находится в `src/stageshow/kit`, лицензия и замечания — рядом.
Button, Field и Tabs дополнены доступными настоящими элементами формы;
ширина текста Button сохраняется корректно и при открытии скрытой мобильной панели.

В приложении нет автоматической анимации с курсором: переходы отвечают действиям
пользователя. Отдельная иллюстрация статичная. Полный вход через клиент MAX
проверяется отдельно после подключения публичного HTTPS-адреса.
