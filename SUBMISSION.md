# Что загрузить на GitHub

Для отправки подготовлены две части:

| Что | Куда загрузить |
| --- | --- |
| Содержимое папки `maximka-github`, расположенной рядом с `maximka-hackathon` | В корень репозитория, вкладка **Code** |
| `maximka-hackathon/artifacts/maxiimka-hackathon-2026-linux-amd64.tar.gz` | Во вложения **Release** этого репозитория |
| `maximka-hackathon/artifacts/SHA256SUMS` | В тот же **Release**, рядом с образом |

В корне репозитория должны быть видны `README.md`, `Dockerfile`, `compose.yaml`,
`requirements.txt`, Python-файлы и папки исходников. Папка `maximka-github` уже
содержит нужные файлы без окружений, кэшей, загруженных учебных материалов и
отдельных файлов текущих ключей. Ключи для жюри находятся внутри готового образа.

## 1. Загрузить исходники

Создай пустой репозиторий на GitHub. Открой терминал в папке `maximka-github`:

```sh
git init
git add .
git commit -m "Prepare МаксИИмка for the hackathon"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

В `git remote add` подставь адрес своего репозитория. Также можно добавить эту
папку через GitHub Desktop и опубликовать репозиторий оттуда.

## 2. Прикрепить Docker-образ

В репозитории открой **Releases → Create a new release**:

1. Создай тег `hackathon-2026` и название «МаксИИмка — хакатон».
2. Прикрепи `.tar.gz` с Docker-образом и `SHA256SUMS` из таблицы выше.
3. Опубликуй Release.

Образ занимает около 1,15 ГБ. В обычном GitHub Git действует ограничение 100 МБ
на файл, поэтому образ размещается во вложениях Release, привязанного к репозиторию.
Архив `maxiimka-hackathon-2026-source.zip` предназначен для локальной передачи
настроенной копии; для вкладки Code используй готовую папку `maximka-github`.

## 3. Отправить ссылку организаторам

Отправь ссылку на репозиторий. Если есть отдельное поле для образа, добавь ссылку
на Release. README содержит команды `docker load`, `docker run`, `docker build`,
Compose и пример запуска через командную строку.

Готовый образ использует сохранённые ключи. Жюри может заменить API-ключ и выбрать
свою модель в **Настройки → Подключение / Модель**; это описано в
[README](README.md#свой-api-ключ-и-другая-модель). Пересобирать образ для этого не нужно.

На время проверки жюри останови свою работающую копию бота: у неё тот же токен MAX.

## Повторная подготовка папки

В локальном комплекте `maximka-hackathon`:

```sh
python scripts/package-source.py
python scripts/prepare-github.py
```

Скрипт создаёт новую папку `maximka-github`. Существующую папку он не перезаписывает;
другой новый путь можно передать первым аргументом.
