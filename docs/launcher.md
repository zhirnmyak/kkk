# Лаунчер МаксИИмки

На Windows запусти `start.cmd` двойным щелчком или командой `.\start.cmd`
из папки проекта. Требуется установленный Python 3.11+ с tkinter и Python Launcher;
вместо Launcher поддерживается `pythonw` из PATH.

## Первый запуск

В небольшом окне подготовки показаны этапы и прогресс:

1. Создание виртуального окружения `.venv`.
2. Установка зависимостей Python, включая pywebview, PyTorch и OCR.
3. Подготовка Node.js и WebView2 при необходимости, установка и сборка интерфейса.
4. Открытие мастера настройки.

Для первой установки нужен интернет. Если подходящего Node.js нет, лаунчер скачивает
Node.js 24 LTS в `.runtime/` и проверяет SHA256. Установщик WebView2 проверяется
по подписи Microsoft. Зависимости занимают несколько гигабайт; подготовка может
занять несколько минут. При ошибке можно нажать «Повторить». Журнал —
`.launcher/install.log`. Прерванное окружение сохраняется в `.launcher/venv-interrupted-*`.

В мастере доступны приветствие, токен MAX и ID администратора, адрес провайдера,
API-ключ и список моделей из `/models`. Для выбранной модели проверяются effort
и изображения. Если `/models` недоступен, можно ввести имя вручную.
Неподтверждённая поддержка изображений не включает Vision: остаётся локальный OCR.
Проверку сети можно отменить. Для Qoder нужны установленный и авторизованный Qoder CLI.

Можно временно выключить MAX и использовать локальную панель. ID администратора
разрешено заполнить позже: свой ID показывает команда `/id` в боте.
Доступны контекст, способ и параллелизм OCR, показ размышлений, индикатор ожидания
и параметры шлюза. Веса поиска и EasyOCR загружаются при первом использовании.

## Следующие запуски

Лаунчер проверяет подготовленное окружение и открывает экран запуска. Галочка
«Открыть панель» независима от режима бота: «Открыть терминал» или «Работать в фоне».
Кнопка «Старт» запускает один процесс. Панель открывается в локальном браузере.
Кнопка «Остановить» доступна и после повторного открытия лаунчера.
Закрытие окна лаунчера оставляет запущенного бота работать.

Настройки хранятся в `data/settings.json`, токен MAX — в `max_token.txt`, ID —
в `.env` и `data/admin.json`. Состояние лаунчера и журнал процесса находятся
в `.launcher/`. Эти файлы исключены из Git. Ключи не возвращаются в интерфейс:
поля показывают только наличие сохранённого ключа.

Локальная панель доступна на этом компьютере. Для встроенной кнопки мини-приложения
в MAX нужен публичный HTTPS-адрес; локальный лаунчер не публикует сайт и не создаёт туннель.

Дизайн использует Stageshow из `webapp/src/stageshow/kit`; отдельная копия скилла —
`webapp/STAGESHOW.md`. Начальное окно подготовки использует стандартный tkinter,
поскольку сторонние библиотеки на этом этапе ещё не установлены.
